# 计量经济学作业 Programs

本文件夹包含两份专业作业水平的计量经济学程序，重点是模型设定、估计、诊断和结果解释。代码使用可复现实验数据，便于直接运行；实际课程作业中可替换为 CSV、Stata 或 Excel 数据。

## Programs

- `ols_diagnostics.py`：多元线性回归、稳健标准误、异方差检验、多重共线性检查和残差诊断。
- `panel_did_analysis.py`：双重差分模型，包括处理组、政策后、交互项设定，以及聚类稳健标准误。

## 知识结构

- 回归模型设定：解释变量、控制变量、误差项假设。
- 统计推断：t 检验、置信区间、稳健标准误。
- 诊断分析：异方差、多重共线性、残差分布。
- 因果识别：处理组与对照组、政策前后、DID 交互项。

## 运行

```bash
python ols_diagnostics.py
python panel_did_analysis.py
```
